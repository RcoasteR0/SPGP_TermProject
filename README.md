# 텀 프로젝트: 카드게임 모음집
## 게임 컨셉
여러 종류의 카드게임을 즐길 수 있는 모음집\
플레이어는 목록에서 게임을 고르고 인공지능을 상대로(혹은 혼자서) 플레이
## 개발 범위
* 게임 목록
  * 클론다이크
  * 블랙잭
  * 원카드
* 터치에 따른 이펙트와 애니메이션
* 플레이 결과에 따른 보상(포인트)
* 상대가 필요한 게임의 경우 인공지능도 제작
* 시간이 된다면 추가적인 게임 제작
  * 프리셀
  * 스파이더
  * 텍사스 홀덤
  * 7포커
  * 대부호
## 게임 흐름
참고 자료: 세계게임전집51\

## 개발 일정
| 1주차 | 기본 프레임워크(목록, 게임) |
|---|---|
| 2주차 | 포인트 시스템 |
| 3주차 | 카드 이펙트 및 애니메이션 |
| 4주차 | 클론다이크 |
| 5주차 | 블랙잭 |
| 6주차 | 원카드 |
| 7주차 | 게임 보완 및 추가 제작 |
| 8주차 | 버그 수정 및 마무리 작업 |
